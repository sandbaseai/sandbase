# Security

Please do not open public issues for security problems.

Report them through [GitHub private vulnerability reporting](../../security/advisories/new) for this repository. Include the affected component (SDK, example, catalog or API), steps to reproduce, and the impact.

We acknowledge reports within 3 business days.

If you accidentally committed an API key, revoke it right away in the [SandBase console](https://www.sandbase.ai/console/keys). Removing it from git history is not enough.

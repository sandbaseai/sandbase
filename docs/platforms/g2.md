# G2 API: 5 endpoints with pricing and code examples

Call 5 G2 endpoints through SandBase with one API key: no separate account, one balance, the same request format for every endpoint. Each page has the input schema, the price and curl / Python / TypeScript / Go examples.

| Endpoint | What it does | Price |
|---|---|---|
| [`g2/categories`](../models/g2/categories.md) | Retrieve the full list of software categories and subcategories available on G2. Returns all categories with name, slug, and URL. | $0.05 per call |
| [`g2/category-products`](../models/g2/category-products.md) | List software products within a given G2 category. Returns products with name, slug, rating, and review count. | $0.05 per call |
| [`g2/product-overview`](../models/g2/product-overview.md) | Retrieve product overview information for a given product slug, including name, description, rating, review count, and logo URL. Uses… | $0.01 per call (free daily quota) |
| [`g2/product-reviews`](../models/g2/product-reviews.md) | Retrieve paginated user reviews for a given software product, 10 reviews per page, newest-first in G2's default order. Each review… | $0.05 per call |
| [`g2/search-software`](../models/g2/search-software.md) | Full-text search over G2's software product catalog. Returns matching products with name, slug, rating, review count, and description. | $0.02 per call |

## Quick start

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "g2/categories"}'
```

Get a key at [sandbase.ai](https://www.sandbase.ai/console). Back to [all platforms](README.md).

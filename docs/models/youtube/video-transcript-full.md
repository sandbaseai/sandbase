## Details

Returns the transcript of a YouTube video or Short as full text and as timed segments. It also says whether the captions were written by the creator or generated by speech recognition. It needs a YouTube video or Short URL.

### Use cases

- Index the spoken text of a video so you can search it by keyword.
- Pull timed lines from a video to build subtitles or jump links to exact moments.
- Check whether a video has creator-written captions before you rely on the text for quoting.
- Collect a video's transcript together with its title, channel and view count for content analysis.

### Request

```bash
curl -X POST "https://api.sandbase.ai/v1/api/youtube/video-transcript-full" \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"}'
```

The result is returned in `outputs[0].data`.

### Response fields

| Field | Meaning |
|---|---|
| `data.transcript` | The full transcript as one string. Segment texts are joined with spaces. |
| `data.segments[].text` | The text of one caption line. |
| `data.segments[].startSeconds / data.segments[].endSeconds` | Start and end time of the caption line, in seconds from the start of the video. |
| `data.isAutoGenerated` | `false` when the captions were written by the creator. Expect `true` for machine speech recognition. |
| `data.isAiGenerated` | Flag for AI-generated text. It is `null` in this response, so treat it as unknown. |
| `data.language` | Language code of the transcript returned. It can differ from the language you asked for. |
| `data.title / data.channel / data.durationSeconds` | Video title, channel name and video length in seconds. |
| `data.views` | View count of the video. |
| `data.authorId / data.authorUrl` | The channel ID and the channel URL of the video's author. |
| `data.videoId / data.url` | The video ID and the canonical watch URL. |

### Notes

- Set `captionKind` to `manual` or `automatic` to accept only that caption type. With either value, no other language is returned.
- If the video has no captions in the requested `language`, you get another language the video has. Check `data.language` to see which one.
- Name fields in `requireFields`, such as `views` or `likes`, when you need them present. This can route the call to a different source and change the price.
- If nothing is found, the call still succeeds and returns `found: false`. For more video metadata, call [YouTube Video Details](/apis/youtube/video-detail).

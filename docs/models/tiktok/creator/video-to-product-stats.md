`tiktok/creator/video-to-product-stats` · data API · TikTok · callable with one SandBase API key from curl, Python, TypeScript and Go.

Returns promotional metrics linking a TikTok video to a specific product, including views, clicks, orders, and revenue trends over time based on video and product identifiers.

## Call it

Modes: sync (default `sync`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "tiktok/creator/video-to-product-stats", "item_id": "7350810998023949599", "product_id": "1732108663255959373"}'
```

## Details

Returns promotional performance metrics linking a TikTok video to a specific product using `item_id` and `product_id`. Filter performance trends from a specific point in time by supplying `start_date`.

### Use cases

- Track product clicks and order counts generated by a specific video.
- Monitor direct revenue and sales trends across periodic time intervals.
- Evaluate creator affiliate performance for specific catalog items.

### Request

```bash
curl -X POST "https://api.sandbase.ai/v1/api/tiktok/creator/video-to-product-stats" \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"item_id": "7350810998023949599", "product_id": "1732108663255959373"}'
```

### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `item_id` | string | Yes | Video ID |
| `product_id` | string | Yes | Product ID |
| `proxy` | string | No | Optional HTTP Proxy Address |
| `start_date` | string | No | Query Start Date, e.g. '04-01-2025' |

### Notes

- Supply `start_date` formatted like '04-01-2025' to filter historical data.
- An optional HTTP proxy address can be set via `proxy`.

Flat price per call. Failed calls, including lookups whose target does not exist, are not charged.

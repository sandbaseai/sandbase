# Ideogram 4.5 Text to Image API: pricing, parameters and code examples

`ideogram/4.5` · image generation model · Ideogram · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** from $0.03 to $0.22 per run, depending on parameters · **Modes:** async

Ideogram 4.5 generates images from a text prompt, with reliable text rendering and polished graphic design output.

## Pricing

- Depends on parameters (`params.quality`).

| parameters | USD |
|---|---|
| quality="low" | 0.03 |
| quality="medium" | 0.06 |
| quality="high" | 0.22 |

Formula: `(params.quality ?? "medium") == "high" ? 0.22 : (params.quality ?? "medium") == "low" ? 0.03 : 0.06`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "ideogram/4.5", "prompt": "a minimalist poster that says HELLO", "quality": "low"}'
```

**Python** ([sdk/python](../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('ideogram/4.5', {'prompt': 'a minimalist poster that says HELLO', 'quality': 'low'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("ideogram/4.5", {
  "prompt": "a minimalist poster that says HELLO",
  "quality": "low"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "ideogram/4.5", sandbase.Params{
	"prompt": "a minimalist poster that says HELLO",
	"quality": "low",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `seed` | integer |  | Random seed. Omit to choose automatically.  |
| `prompt` | string | yes | The generation or editing prompt.  |
| `quality` | string |  | Text-to-image quality. one of: `low`, `medium`, `high`; default `"medium"` |
| `aspect_ratio` | string |  | The aspect ratio of the generated image. one of: `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16` |

## Details

Ideogram 4.5 generates images with reliable text rendering and polished graphic design, at three quality levels.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | Up to 10,000 characters. |
| `aspect_ratio` | `21:9` / `16:9` / `3:2` / `4:3` / `5:4` / `1:1` / `4:5` / `3:4` / `2:3` / `9:16` | — | Output shape. |
| `seed` | integer | random | Fix it to compare prompt changes. |
| `quality` | `low` / `medium` / `high` | `medium` | Sets the per-image rate. |

### Billing

Per image: $0.03 low, $0.06 medium, $0.22 high.

| Quality | Price |
|---|---|
| low | $0.03 |
| medium | $0.06 |
| high | $0.22 |

Failed runs are not charged.

### Prompting

- Quote all text that must appear.

### Limits

# Ideogram 4.6 Text to Image API: pricing, parameters and code examples

`ideogram/4.6` · image generation model · Ideogram · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** from $0.008 to $0.1 per run, depending on parameters · **Modes:** async

Ideogram 4.6 generates images with reliable text rendering and polished graphic design, with four quality levels from very_low to high.

## Pricing

- Depends on parameters (`params.quality`).

| parameters | USD |
|---|---|
| quality="very_low" | 0.008 |
| quality="low" | 0.03 |
| quality="medium" | 0.06 |
| quality="high" | 0.1 |

Formula: `(params.quality ?? "medium") == "high" ? 0.10 : (params.quality ?? "medium") == "low" ? 0.03 : (params.quality ?? "medium") == "very_low" ? 0.008 : 0.06`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "ideogram/4.6", "aspect_ratio": "16:9", "prompt": "A vintage travel poster for Kyoto with the headline \"KYOTO\" in bold art deco letters, pagoda and cherry blossoms"}'
```

**Python** ([sdk/python](../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('ideogram/4.6', {'aspect_ratio': '16:9', 'prompt': 'A vintage travel poster for Kyoto with the headline "KYOTO" in bold art deco letters, pagoda and cherry blossoms'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("ideogram/4.6", {
  "aspect_ratio": "16:9",
  "prompt": "A vintage travel poster for Kyoto with the headline \"KYOTO\" in bold art deco letters, pagoda and cherry blossoms"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "ideogram/4.6", sandbase.Params{
	"aspect_ratio": "16:9",
	"prompt": "A vintage travel poster for Kyoto with the headline \"KYOTO\" in bold art deco letters, pagoda and cherry blossoms",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `seed` | integer |  | Random seed. Omit to choose automatically.  |
| `prompt` | string | yes | The generation or editing prompt.  |
| `quality` | string |  | Text-to-image quality. one of: `very_low`, `low`, `medium`, `high`; default `"medium"` |
| `aspect_ratio` | string |  | The aspect ratio of the generated image. one of: `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16` |

## Details

Ideogram 4.6 generates images with reliable text rendering and polished graphic design, at four quality levels.

# Kling Image V4 API: pricing, parameters and code examples

`kwaivgi/kling-image/v4` · image generation model · KwaiVGI · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** from $0.063 to $1.413 per run, depending on parameters · **Modes:** async

Kling Image V4 by Kuaishou generates photorealistic images with accurate text rendering from a text prompt at native 2K, 4K or 8K resolution.

## Pricing

- Depends on parameters (`params.num_images`, `params.resolution`).

| parameters | USD |
|---|---|
| num_images=1, resolution="2K" | 0.063 |
| num_images=1, resolution="4K" | 0.094 |
| num_images=1, resolution="8K" | 0.157 |
| num_images=9, resolution="2K" | 0.567 |
| num_images=9, resolution="4K" | 0.846 |
| num_images=9, resolution="8K" | 1.413 |

Formula: `(params.num_images ?? 1) * ((params.resolution ?? "2K") == "8K" ? 0.157 : (params.resolution ?? "2K") == "4K" ? 0.094 : 0.063)`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "kwaivgi/kling-image/v4", "aspect_ratio": "16:9", "prompt": "Event poster for a jazz night: a saxophonist silhouetted against a deep blue stage light, large title \"MIDNIGHT JAZZ\" in bold Art Deco letters, smaller line \"Friday 22 November · Blue Room · 9 PM\" at the bottom, grainy film texture."}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('kwaivgi/kling-image/v4', {'aspect_ratio': '16:9', 'prompt': 'Event poster for a jazz night: a saxophonist silhouetted against a deep blue stage light, large title "MIDNIGHT JAZZ" in bold Art Deco letters, smaller line "Friday 22 November · Blue Room · 9 PM" at the bottom, grainy film texture.'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("kwaivgi/kling-image/v4", {
  "aspect_ratio": "16:9",
  "prompt": "Event poster for a jazz night: a saxophonist silhouetted against a deep blue stage light, large title \"MIDNIGHT JAZZ\" in bold Art Deco letters, smaller line \"Friday 22 November · Blue Room · 9 PM\" at the bottom, grainy film texture."
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "kwaivgi/kling-image/v4", sandbase.Params{
	"aspect_ratio": "16:9",
	"prompt": "Event poster for a jazz night: a saxophonist silhouetted against a deep blue stage light, large title \"MIDNIGHT JAZZ\" in bold Art Deco letters, smaller line \"Friday 22 November · Blue Room · 9 PM\" at the bottom, grainy film texture.",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `prompt` | string | yes | Describe the image. Refer to reference images as @Image1, @Image2, ...  |
| `num_images` | integer |  | Number of independent images to generate (1-9). default `1`; range 1–9 |
| `resolution` | string |  | Output resolution. 8K is native ultra-high resolution. one of: `2K`, `4K`, `8K`; default `"2K"` |
| `aspect_ratio` | string |  | Output frame shape. auto picks one from the prompt and references. one of: `auto`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9`; default `"auto"` |

## Details

Kling Image V4 generates photorealistic images from a text prompt at native 2K, 4K or 8K, with sharp in-image text (up to about 2,000 characters, multilingual) and dense layouts.
### Fields
| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | Put any text to render in quotation marks. |
| `aspect_ratio` | `auto` / `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `3:2` / `2:3` / `21:9` | `auto` | `auto` picks a shape from the prompt and references. |
| `resolution` | `2K` / `4K` / `8K` | `2K` | Native output resolution. |
| `num_images` | 1–9 | 1 | Independent images, each billed. |
### Billing
Billed per output image by resolution.
| Resolution | Per image |
|---|---|
| 2K (default) | $0.063 |
| 4K | $0.094 |
| 8K | $0.157 |
Failed runs are not charged.
### Prompting
- Quote the exact text you want rendered, e.g. a poster title "SUMMER SALE".
- Describe subject, material, light and camera in order.

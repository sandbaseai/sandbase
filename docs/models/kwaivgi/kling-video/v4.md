# Kling V4 API: pricing, parameters and code examples

`kwaivgi/kling-video/v4` · video generation model · KwaiVGI · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** about $1.175 per call · **Modes:** async

Kling V4 by KwaiVGI in one endpoint: generate 3-30 second videos with native audio from text, start and end frames, reference images and reference videos, at 720p, 1080p or 4K.

## Pricing

- Depends on parameters (`params.duration`, `params.dynamic_range`, `params.resolution`, `params.videos`).

Formula: see the JSON record.

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "kwaivgi/kling-video/v4", "prompt": "A detective in a black trench coat stands on a rooftop in the rain, looking through a telescope at the street below."}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('kwaivgi/kling-video/v4', {'prompt': 'A detective in a black trench coat stands on a rooftop in the rain, looking through a telescope at the street below.'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("kwaivgi/kling-video/v4", {
  "prompt": "A detective in a black trench coat stands on a rooftop in the rain, looking through a telescope at the street below."
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "kwaivgi/kling-video/v4", sandbase.Params{
	"prompt": "A detective in a black trench coat stands on a rooftop in the rain, looking through a telescope at the street below.",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `image` | string |  | Optional first frame. Min 300x300 px, aspect ratio 0.4-2.5, up to 30 MB.  |
| `images` | array |  | Up to 10 reference images, referenced as @Image1, @Image2, ...  |
| `prompt` | string | yes | Text prompt. Refer to reference inputs as @Image1, @Video1, ...  |
| `videos` | array |  | Up to 5 reference videos (3-30s each, 30s combined), referenced as @Video1, ... Video references switch to the input-plus-output price.  |
| `duration` | integer |  | Output length in seconds (3-30). default `5`; range 3–30 |
| `end_image` | string |  | Optional last frame. Use together with image.  |
| `voice_ids` | array |  | Up to 2 custom voice IDs so characters speak in that voice. Create one by uploading a 5-30s voice recording at https://www.sandbase.ai/model/kwaivgi/kling-video/create-voice (Kling Create Voice). Cannot be combined…  |
| `resolution` | string |  | Output resolution. one of: `720p`, `1080p`, `4k`; default `"1080p"` |
| `aspect_ratio` | string |  | Output frame shape. Leave empty to follow the references (adaptive). one of: `21:9`, `16:9`, `9:16`, `1:1` |
| `dynamic_range` | string |  | hdr outputs 10-bit HDR video; 1080p and 4k only. one of: `sdr`, `hdr`; default `"sdr"` |

## Details

Kling V4 in a single endpoint: text-to-video, start/end-frame image-to-video, and reference-to-video, 3–30 seconds with native audio.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | Refer to references as `@Image1`, `@Video1`, … |
| `image` | image URL | — | Optional first frame. |
| `end_image` | image URL | — | Optional last frame. |
| `images` | image URL[] | — | Up to 10 reference images. |
| `videos` | video URL[] | — | Up to 5 reference videos, 3–30s each, 30s combined. |
| `voice_ids` | string[] | — | Up to 2 custom voice IDs from [Kling Create Voice](https://www.sandbase.ai/model/kwaivgi/kling-video/create-voice). Not combinable with `videos`. |
| `aspect_ratio` | `21:9` / `16:9` / `9:16` / `1:1` | — | Leave empty to follow the inputs. |
| `resolution` | `720p` / `1080p` / `4k` | `1080p` | Output resolution. |
| `dynamic_range` | `sdr` / `hdr` | `sdr` | `hdr` outputs 10-bit HDR video. 1080p and 4k only. |
| `duration` | 3–30 | 5 | Output length in seconds. |

### Billing

Without reference videos: $0.157 per output second at 720p, $0.235 at 1080p, $0.549 at 4K.
With reference videos: $0.094 (720p), $0.141 (1080p) or $0.329 (4K) per second of output plus input, where the input side counts at least as long as the output. The quote before submission assumes 30 seconds of reference video when the length cannot be read.

HDR adds $0.047 per output second at 1080p and $0.078 at 4K.
| Request | Price |
|---|---|
| 5s, 1080p, text or images (default) | $1.175 |
| 5s, 720p, text or images | $0.785 |
| 5s, 4K, text or images | $2.745 |
| 5s, 4K, text or images, HDR | $3.135 |
| 5s, 1080p, 8s reference video | $1.833 |

Failed runs are not charged.

### Limits

- Clips are 3–30 seconds; reference videos 3–30 seconds.

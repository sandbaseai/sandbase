# HeyGen Video Agent V3 API: pricing, parameters and code examples

`heygen/video-agent/v3` · video generation model · HeyGen · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** about $1.02 per call · **Modes:** async

Heygen Video Agent V3 is HeyGen's text-to-video AI model. Turn written scripts and prompts into professional-quality video clips with realistic motion, lighting, and scene composition.

## Pricing

- Depends on parameters (`usage.duration`).

Formula: `Math.ceil(usage.duration ?? 30.0) * 0.034`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "heygen/video-agent/v3", "prompt": "Create a 30-second product demo video showcasing our new AI features with professional lighting and modern graphics."}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('heygen/video-agent/v3', {'prompt': 'Create a 30-second product demo video showcasing our new AI features with professional lighting and modern graphics.'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("heygen/video-agent/v3", {
  "prompt": "Create a 30-second product demo video showcasing our new AI features with professional lighting and modern graphics."
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "heygen/video-agent/v3", sandbase.Params{
	"prompt": "Create a 30-second product demo video showcasing our new AI features with professional lighting and modern graphics.",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `prompt` | string | yes | Natural language prompt describing the video to generate. The agent handles avatar selection, script, and production automatically.  |

## Details

HeyGen Video Agent: describe the video you want and the agent writes, voices, and edits a complete presenter video.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | What the video should cover, its audience, length, and tone. |

### Billing

$0.034 per output second (rounded up). The quote before submission assumes 30 seconds.

| Output | Price |
|---|---|
| 30s | $1.02 |
| 60s | $2.04 |
| 120s | $4.08 |

Failed runs are not charged.

### Prompting

- State the target length in the prompt.

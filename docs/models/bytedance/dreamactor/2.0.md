# ByteDance DreamActor 2.0

`bytedance/dreamactor/2.0` · video · Bytedance

## Parameters

| name | type | required | description |
|---|---|---|---|
| `image` | string | yes | Input image URL (face / character).  |
| `video` | string | yes | Driving video providing motion, expressions and lip movement.  |
| `trim_first_second` | boolean |  | Crop the 1-second transition at the start of the output. default `true` |

## Details

DreamActor 2.0 transfers body motion, facial expression, and lip movement from a driving `video` to the character in `image`.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `image` | image URL, required | — | Character to animate. JPEG, PNG, or WebP URL. |
| `video` | video URL, required | — | Driving video that supplies motion and expression. |
| `trim_first_second` | boolean | true | Drop the first second, which is often used for alignment. |

### Billing

$0.05 per output second. The quote before submission assumes 5 seconds; the final charge uses the measured length.

| Output | Price |
|---|---|
| 5s | $0.25 |
| 10s | $0.50 |
| 30s | $1.50 |

Failed runs are not charged.

### Prompting

- Use a driving video with one clearly visible face and body.
- Match the character image's framing to the driving video.

### Limits

- Output length follows the driving video.

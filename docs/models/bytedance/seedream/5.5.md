# Seedream 5.5 Text to Image API: pricing, parameters and code examples

`bytedance/seedream/5.5` · image generation model · Bytedance · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** from $0.02 to $0.035 per run, depending on parameters · **Modes:** async

Seedream 5.5 by ByteDance generates photorealistic images from text prompts, with accurate small and multilingual text and native transparent-background (RGBA) output. Choose 1K, 1.5K or 2K resolution and ten aspect ratios.

## Pricing

- Depends on parameters (`params.num_images`, `params.resolution`).

| parameters | USD |
|---|---|
| num_images=1, resolution="1K" | 0.02 |
| num_images=1, resolution="1.5K" | 0.02 |
| num_images=1, resolution="2K" | 0.035 |

Formula: `(params.num_images ?? 1) * ((params.resolution ?? "2K") == "2K" ? 0.035 : 0.02)`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "bytedance/seedream/5.5", "aspect_ratio": "16:9", "prompt": "Vibrant editorial of a model in contemporary fashion fused with West African textile patterns and beadwork, Campbell Addy bold aesthetic, saturated palette, dramatic studio lighting, celebratory cultural richness, striking contemporary portraiture"}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('bytedance/seedream/5.5', {'aspect_ratio': '16:9', 'prompt': 'Vibrant editorial of a model in contemporary fashion fused with West African textile patterns and beadwork, Campbell Addy bold aesthetic, saturated palette, dramatic studio lighting, celebratory cultural richness, striking contemporary portraiture'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("bytedance/seedream/5.5", {
  "aspect_ratio": "16:9",
  "prompt": "Vibrant editorial of a model in contemporary fashion fused with West African textile patterns and beadwork, Campbell Addy bold aesthetic, saturated palette, dramatic studio lighting, celebratory cultural richness, striking contemporary portraiture"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "bytedance/seedream/5.5", sandbase.Params{
	"aspect_ratio": "16:9",
	"prompt": "Vibrant editorial of a model in contemporary fashion fused with West African textile patterns and beadwork, Campbell Addy bold aesthetic, saturated palette, dramatic studio lighting, celebratory cultural richness, striking contemporary portraiture",

```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `prompt` | string | yes | The text prompt used to generate the image.  |
| `background` | string |  | auto lets the model decide; transparent returns a PNG with an alpha channel (requires png output); opaque never adds transparency. one of: `auto`, `transparent`, `opaque`; default `"auto"` |
| `num_images` | integer |  | The number of images to generate. Currently limited to 1. default `1`; range 1–1 |
| `resolution` | string |  | Output resolution tier. 1K and 1.5K cost less; 2K is the highest quality. one of: `1K`, `1.5K`, `2K`; default `"2K"` |
| `aspect_ratio` | string |  | The aspect ratio of the generated image. Leave unset to let the model choose from the prompt. one of: `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16` |
| `output_format` | string |  | The file format of the generated image. Use png for transparent backgrounds. one of: `jpeg`, `png`; default `"png"` |

## Details

Seedream 5.5 is ByteDance's latest image model (November 2026). It renders photorealistic textures and dense small or multilingual text, and it can output transparent-background (RGBA) PNGs directly from a prompt.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | Text instruction. |
| `aspect_ratio` | `21:9` / `16:9` / `3:2` / `4:3` / `5:4` / `1:1` / `4:5` / `3:4` / `2:3` / `9:16` | — | Output shape. Omit to let the model choose from the prompt. |
| `resolution` | `1K` / `1.5K` / `2K` | `2K` | Output resolution tier. 2K at 16:9 is 2816×1584. |
| `background` | `auto` / `transparent` / `opaque` | `auto` | `transparent` returns a PNG with an alpha channel. |
| `num_images` | integer 1–1 | 1 | Fixed at 1. |
| `output_format` | `png` / `jpeg` | `png` | Use `png` for transparent backgrounds. |

### Billing

$0.035 per image at 2K, $0.02 at 1K or 1.5K.

| Request | Price |
|---|---|
| One image, 1K or 1.5K | $0.02 |
| One image, 2K | $0.035 |

Failed runs are not charged.

### Prompting

- Write subject, layout, style, then light and color.
- Quote any text that must appear, and say where it goes.
- For a cut-out asset, describe the subject on its own, ask for a transparent background, and set `background` to `transparent`.

### Limits

- One output image per request.
- `jpeg` output never has transparency, even with `background` set to `transparent`.

# Bytedance Seed Speech Text to Speech

`bytedance/seed-speech/tts/2.0` · audio · Bytedance

Seed Speech Tts 2.0 is Bytedance's text-to-speech AI model. Generate human-like voiceovers with expressive intonation, multilingual support, and customizable voice characteristics.

## Parameters

| name | type | required | description |
|---|---|---|---|
| `text` | string |  | The text to synthesize into speech.  |
| `pitch` | integer |  | Voice pitch shift in semitones. 0 is normal pitch, -12 lowers by one octave, 12 raises by one octave. default `0`; range -12–12 |
| `speed` | number |  | Speech speed. 1.0 is normal speed, 0.5 is half speed, 2.0 is double speed. default `1`; range 0.5–2 |
| `voice` | string |  | Voice to use for synthesis. The preset name encodes the voice and its supported language codes. 'mixed_en_zh' means the voice can seamlessly blend English and Chinese; separate codes (e.g. 'en_zh') mean the voice… one of: `vivi_mixed_en_zh_ja_es_id`, `mindy_en_es_id_pt_zh`, `stokie_en`, `dacey_en`, `tim_en`, `kian_en_zh`, `cedric_en_zh`, `sophie_en_zh`, `jean_en_zh`, `magnus_en_zh`, `mabel_en_zh`, `nadia_en_zh` …; default `"stokie_en"` |
| `volume` | number |  | Volume. 1.0 is normal volume, 0.5 is half, 2.0 is double. default `1`; range 0.5–2 |
| `language` | string |  | Force the text to be read as a single language, disabling automatic language detection. Leave unset for automatic detection (including seamless Chinese/English mixing on bilingual voices). Codes: zh (Chinese), en… one of: `zh`, `en`, `ja`, `es-mx`, `id`, `pt-br`, `ko`, `it`, `de`, `fr` |
| `sample_rate` | integer |  | Sample rate of the output audio in Hz. one of: `8000`, `16000`, `22050`, `24000`, `32000`, `44100`, `48000`; default `24000` |
| `output_format` | string |  | Output audio format. 'mp3' returns MP3 audio; 'opus' returns Opus audio in an Ogg container. one of: `mp3`, `opus`; default `"mp3"` |
| `voice_instruction` | string |  | Optional natural-language instruction that steers the delivery (tone, emotion, pace, volume), e.g. 'Speak in a cheerful tone' or 'Could you speak a bit slower?'. It is not spoken aloud and does not affect billing.  |

## Details

Seed Speech TTS 2.0 generates expressive, multilingual voiceovers in 10 languages, with pitch, speed, and volume control and a free-text `voice_instruction` for delivery.

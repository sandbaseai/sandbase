# ByteDance OmniHuman 1.5

`bytedance/omnihuman/1.5` · video · Bytedance

Omnihuman 1.5 is Bytedance's image-to-video AI model. Bring static images to life with fluid animation, consistent character motion, and professional-grade video output.

## Pricing

- Depends on parameters (`params.audio`, `usage.duration`).

Formula: `(usage.duration ?? media_duration(params.audio) ?? 5.0) * 0.16`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "bytedance/omnihuman/1.5", "prompt": "<prompt>", "image": "<image>", "audio": "<audio>"}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('bytedance/omnihuman/1.5', {'prompt': '<prompt>', 'image': '<image>', 'audio': '<audio>'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("bytedance/omnihuman/1.5", {
  "prompt": "<prompt>",
  "image": "<image>",
  "audio": "<audio>"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "bytedance/omnihuman/1.5", sandbase.Params{
	"prompt": "<prompt>",

```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `mask` | string |  | The URL of the mask image to apply to the image. Only the person in the white area of the mask will speak.  |
| `audio` | string | yes | The URL of the audio file to generate the video. Audio must be under 30s long for 1080p generation and under 60s long for 720p generation.  |
| `image` | string | yes | The URL of the image used to generate the video  |
| `prompt` | string | yes | The text prompt used to guide the video generation.  |
| `resolution` | string |  | The resolution of the generated video. Defaults to 1080p. 720p generation is faster and higher in quality. 1080p generation is limited to 30s audio and 720p generation is limited to 60s audio. one of: `720p`, `1080p`; default `"720p"` |
| `turbo_mode` | boolean |  | Generate a video at a faster rate with a slight quality trade-off. default `false` |

## Details

OmniHuman 1.5 turns a single image and an audio track into a talking or performing video, with lip sync, gestures, and expressions that follow the audio and the prompt.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | Optional direction for gestures and camera. |
| `image` | image URL, required | — | Person or character to animate. JPEG, PNG, or WebP URL. |
| `mask` | image URL | — | Optional mask to choose which person speaks. |
| `audio` | audio URL, required | — | Speech or song that drives the performance. |
| `resolution` | `720p` / `1080p` | `720p` | Output resolution. |
| `turbo_mode` | boolean | false | Faster generation at some quality cost. |

### Billing

$0.16 per output second; the output is as long as the audio. The quote before submission assumes 5 seconds.

| Audio | Price |
|---|---|
| 5s audio | $0.80 |
| 15s audio | $2.40 |
| 30s audio | $4.80 |

Failed runs are not charged.

### Prompting

- Describe gestures and camera; the lips follow the audio automatically.

### Limits

- Output length follows the audio.

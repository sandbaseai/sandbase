# Weibo User Original Posts API: pricing, parameters and code examples

`weibo/web-v2/user-original-posts` · data API · Weibo · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** $0.001 per call (free daily quota) · **Modes:** sync

Returns original posts shared by a specified user, excluding reposts. Results support pagination by page number or pagination identifier.

## Pricing

- **$0.001 per call** (USD)
- Free quota: 100 calls/day per organization (shared across free-quota APIs).

## Call it

Modes: sync (default `sync`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "weibo/web-v2/user-original-posts", "uid": "8431518763"}'
```

**Python** ([sdk/python](../../../../sdk/python))

## Details

Retrieves a feed of original posts for a specified Weibo user by `uid`, filtering out reposts.

### Use cases

- Audit a specific user's original content without repost clutter.
- Analyze posting trends and engagement on authored Weibo updates.
- Archive historical posts directly generated by an account.

### Request

```bash
curl -X POST "https://api.sandbase.ai/v1/api/weibo/web-v2/user-original-posts" \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"uid": "8431518763"}'
```

### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `uid` | string | Yes | User ID (required) |
| `page` | integer | No | Page number, starts from 1 (default 1) |
| `since_id` | string | No | Pagination identifier (first page must get from fetch_user_posts) |

### Notes

- The `page` parameter starts from 1 and defaults to 1.
- Obtain the initial `since_id` value from the user posts endpoint for subsequent page queries.

### Pricing

Flat price per call. Failed calls, including lookups whose target does not exist, are not charged.

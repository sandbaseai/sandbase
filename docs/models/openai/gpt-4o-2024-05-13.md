# OpenAI: GPT-4o (2024-05-13)

`openai/gpt-4o-2024-05-13` · llm · OpenAI

This is the pinned May 13, 2024 snapshot of OpenAI's GPT-4o, the original API release of the model, with text and image input and text output. It is intended for workloads that need a fixed, reproducible version of the launch-era GPT-4o rather than the moving GPT-4o alias. Later snapshots from August and November 2024 add Structured Outputs with JSON schemas and a larger output limit, so most fresh projects start with one of those.

## Pricing

- Input **$5** / output **$15** per 1M tokens (USD)
- cache read multiplier: 0.5

## Call it

OpenAI-compatible: any OpenAI SDK works with `base_url=https://api.sandbase.ai/v1`. Anthropic (`/v1/messages`) and Gemini (`/v1beta/models/...`) formats are also accepted.

**curl**

```bash
curl https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "openai/gpt-4o-2024-05-13", "messages": [{"role": "user", "content": "Hello"}]}'
```

**Python**

```python
from openai import OpenAI

client = OpenAI(base_url="https://api.sandbase.ai/v1", api_key=os.environ["SANDBASE_API_KEY"])
resp = client.chat.completions.create(model='openai/gpt-4o-2024-05-13', messages=[{"role": "user", "content": "Hello"}])
```

**TypeScript**

```ts
import OpenAI from "openai";

const client = new OpenAI({ baseURL: "https://api.sandbase.ai/v1", apiKey: process.env.SANDBASE_API_KEY });
const resp = await client.chat.completions.create({ model: "openai/gpt-4o-2024-05-13", messages: [{ role: "user", content: "Hello" }] });
```

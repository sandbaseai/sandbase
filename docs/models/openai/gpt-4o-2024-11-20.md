# OpenAI: GPT-4o (2024-11-20) API: pricing, parameters and code examples

`openai/gpt-4o-2024-11-20` · LLM · OpenAI · callable with one SandBase API key from curl, Python, TypeScript and Go.

This is the pinned November 20, 2024 snapshot of OpenAI's GPT-4o, with text and image input and text output, plus Structured Outputs and function calling. It is the most recent of the dated GPT-4o snapshots OpenAI lists in the API, following the August 2024 release. Use it for workloads that need a fixed GPT-4o version from late 2024 rather than the moving GPT-4o alias.

## Call it

OpenAI-compatible: any OpenAI SDK works with `base_url=https://api.sandbase.ai/v1`. Anthropic (`/v1/messages`) and Gemini (`/v1beta/models/...`) formats are also accepted.

**curl**

```bash
curl https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "openai/gpt-4o-2024-11-20", "messages": [{"role": "user", "content": "Hello"}]}'
```

**Python**

```python
from openai import OpenAI

client = OpenAI(base_url="https://api.sandbase.ai/v1", api_key=os.environ["SANDBASE_API_KEY"])
resp = client.chat.completions.create(model='openai/gpt-4o-2024-11-20', messages=[{"role": "user", "content": "Hello"}])
```

**TypeScript**

```ts
import OpenAI from "openai";

const client = new OpenAI({ baseURL: "https://api.sandbase.ai/v1", apiKey: process.env.SANDBASE_API_KEY });
const resp = await client.chat.completions.create({ model: "openai/gpt-4o-2024-11-20", messages: [{ role: "user", content: "Hello" }] });
```

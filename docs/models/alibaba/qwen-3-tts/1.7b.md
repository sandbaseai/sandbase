## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "alibaba/qwen-3-tts/1.7b", "prompt": "Very happy."}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('alibaba/qwen-3-tts/1.7b', {'prompt': 'Very happy.'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("alibaba/qwen-3-tts/1.7b", {
  "prompt": "Very happy."
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "alibaba/qwen-3-tts/1.7b", sandbase.Params{
	"prompt": "Very happy.",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `text` | string |  | The text to be converted to speech.  |
| `top_k` | integer |  | Top-k sampling parameter. default `50`; range 0– |
| `top_p` | number |  | Top-p sampling parameter. default `1`; range 0–1 |
| `voice` | string |  | The voice to be used for speech synthesis, will be ignored if a speaker embedding is provided. Check out the **[documentation](https://github.com/QwenLM/Qwen3-TTS/tree/main?tab=readme-ov-file#custom-voice-generate)**… one of: `Vivian`, `Serena`, `Uncle_Fu`, `Dylan`, `Eric`, `Ryan`, `Aiden`, `Ono_Anna`, `Sohee` |
| `prompt` | string | yes | Optional prompt to guide the style of the generated speech. This prompt will be ignored if a speaker embedding is provided.  |
| `language` | string |  | The language of the voice. one of: `Auto`, `English`, `Chinese`, `Spanish`, `French`, `German`, `Italian`, `Japanese`, `Korean`, `Portuguese`, `Russian`; default `"Auto"` |
| `temperature` | number |  | Sampling temperature; higher => more random. default `0.9`; range 0–1 |
| `max_new_tokens` | integer |  | Maximum number of new codec tokens to generate. default `200`; range 1–8192 |
| `reference_text` | string |  | Optional reference text that was used when creating the speaker embedding. Providing this can improve synthesis quality when using a cloned voice.  |
| `subtalker_top_k` | integer |  | Top-k for sub-talker sampling. default `50`; range 0– |
| `subtalker_top_p` | number |  | Top-p for sub-talker sampling. default `1`; range 0–1 |
| `repetition_penalty` | number |  | Penalty to reduce repeated tokens/codes. default `1.05`; range 0– |
| `subtalker_dosample` | boolean |  | Sampling switch for the sub-talker. default `true` |
| `subtalker_temperature` | number |  | Temperature for sub-talker sampling. default `0.9`; range 0–1 |
| `speaker_voice_embedding_file_url` | string |  | URL to a speaker embedding file in safetensors format. If provided, the TTS model will use the cloned voice for synthesis instead of the predefined voices.  |

## Details

Qwen 3 TTS 1.7B, the open-weights Qwen speech model: text to speech in 10 languages with nine preset voices, or a cloned voice from a speaker-embedding file. The 1.7B model gives more natural prosody than 0.6B.

### Prompting

- Use punctuation to control pauses; break long passages into paragraphs.
- Pick a voice whose primary language matches the text.

### Limits

- `max_new_tokens` (default 200) caps the audio length; long text needs a higher value.

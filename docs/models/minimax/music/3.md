# MiniMax Music 3

`minimax/music/3` · audio · MiniMax

MiniMax Music 3 by MiniMax composes a complete song up to five minutes long with expressive vocals and evolving arrangements from a style prompt and lyrics.

| parameters | USD |

\* estimate: assumes output duration equals requested duration.

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "minimax/music/3", "duration": 30, "lyrics": "[verse]\nMorning light filtering through the pine\n[chorus]\nSoftly the world begins to breathe", "prompt": "Genre: acoustic pop. BPM: 96. Warm and intimate. Vocals: soft female lead."}'
```


## Parameters

| name | type | required | description |
|---|---|---|---|
| `seed` | integer |  | Random seed for reproducible results. Omit for a random seed. range 0–2147483647 |
| `lyrics` | string | yes | Lyrics to sing. Put structure tags such as [intro], [verse], [chorus], [bridge], [instrumental], and [outro] on their own lines.  |
| `prompt` | string | yes | Music description: style, mood, vocals, instrumentation, and arrangement.  |
| `duration` | integer |  | Upper bound on the generated song length in seconds (1-300). The model may stop earlier; billing uses this upper bound. default `60`; range 1–300 |

## Details

MiniMax Music 3 composes a complete song up to five minutes long, with expressive vocals and evolving arrangements, from a style prompt and your lyrics.

### Fields

| Field | Type | Default | Notes |
|---|---|---|---|
| `prompt` | string, required | — | Style: genre, mood, instruments, tempo. |
| `lyrics` | string, required | — | Song lyrics; mark sections like `[verse]`, `[chorus]`. |
| `duration` | integer 1–300 | 60 | Song length in seconds (1–300). |
| `seed` | integer 0–2147483647 | random | Fix it to compare prompt changes. |

### Billing

$0.002 per second of music; the final charge uses the generated length.

| Song | Price |
|---|---|
| 30s | $0.06 |
| 60s | $0.12 |
| 180s | $0.36 |
| 300s | $0.60 |

Failed runs are not charged.

### Prompting

- Keep style and lyrics separate: style in `prompt`, words in `lyrics`.

### Limits

- Up to 5 minutes.

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "minimax/music/2.6", "lyrics": "[verse]\nMorning light on the water\n[chorus]\nWe keep on running", "prompt": "Upbeat indie pop, bright guitars, female vocal"}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('minimax/music/2.6', {'lyrics': '[verse]\nMorning light on the water\n[chorus]\nWe keep on running', 'prompt': 'Upbeat indie pop, bright guitars, female vocal'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("minimax/music/2.6", {
  "lyrics": "[verse]\nMorning light on the water\n[chorus]\nWe keep on running",
  "prompt": "Upbeat indie pop, bright guitars, female vocal"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "minimax/music/2.6", sandbase.Params{
	"lyrics": "[verse]\nMorning light on the water\n[chorus]\nWe keep on running",
	"prompt": "Upbeat indie pop, bright guitars, female vocal",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `format` | string |  | Format of generated audio. one of: `mp3`, `wav`, `pcm` |
| `lyrics` | string |  | Lyrics of the song. Use \n to separate lines. Supports structure tags: [Intro], [Verse], [Pre Chorus], [Chorus], [Bridge], [Outro], [Interlude], [Hook], [Break], [Solo], [Inst]. default `"[verse]\nStreetlights flicker, the night breeze sighs\nShadows stretch as I walk alone\nAn old coat wraps my silent sorrow\nWandering, longing, where should I go\n[chorus]\nPushing the wooden door, the aroma spreads\nIn a familiar corner, a stranger gazes"` |
| `prompt` | string | yes | A description of the music style, mood, genre, and scenario. default `"Indie folk, melancholic, introspective, longing, solitary walk, coffee shop"` |
| `bitrate` | integer |  | Bitrate of generated audio. one of: `32000`, `64000`, `128000`, `256000` |
| `sample_rate` | integer |  | Sample rate of generated audio. one of: `16000`, `24000`, `32000`, `44100` |
| `is_instrumental` | boolean |  | When true, generates vocal-free instrumental music. default `false` |
| `lyrics_optimizer` | boolean |  | When true and lyrics is empty, auto-generates lyrics from the prompt. default `false` |

## Details

# Bing Shopping Product API: pricing, parameters and code examples

`bing-shopping/product` · data API · Bing Shopping · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** $0.01 per call · **Modes:** sync

Get a Bing Shopping product by product token with title, specifications, rating, reviews and offers from each merchant.

## Pricing

- **$0.01 per call** (USD)

## Call it

Modes: sync (default `sync`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "bing-shopping/product", "product_token": "<product_token>"}'
```

**Python** ([sdk/python](../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('bing-shopping/product', {'product_token': '<product_token>'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("bing-shopping/product", {
  "product_token": "<product_token>"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "bing-shopping/product", sandbase.Params{
	"product_token": "<product_token>",
})
```

Same call via the path form: `POST /v1/api/bing-shopping/product` with the body above minus `model`.

## Details

Get a Bing Shopping product by product token with title, specifications, rating, reviews and offers from each merchant.

### Request

```bash
curl -X POST "https://api.sandbase.ai/v1/api/bing-shopping/product" \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"product_token": "<product_token from search results>"}'
```

The result is returned in `outputs[0].data` as structured JSON.

### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `product_token` | string | Yes | Parameter defines the token needed to retrieve specific product details. The token is generated by the API using our Bing Shopping API. |
| `json_restrictor` | string | No | Parameter defines the fields you want to include in the output, reducing payload size for faster response. See the JSON Restrictor documentation for more details. |

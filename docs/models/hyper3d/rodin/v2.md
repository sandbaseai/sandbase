# Rodin Gen-2 Image to 3D API: pricing, parameters and code examples

`hyper3d/rodin/v2` · image generation model · hyper3d · callable with one SandBase API key from curl, Python, TypeScript and Go.

**Price:** from $1.2 per run, depending on parameters · **Modes:** async

Rodin Gen-2 by Hyper3D (Deemos) generates production-ready 3D assets from one to five reference images.

## Pricing

- Depends on parameters (`params.addons`).

| parameters | USD |
|---|---|
| addons="HighPack" | 1.2 |

Formula: `(params.addons ?? "") == "HighPack" ? 1.2 : 0.4`

## Call it

Modes: async (default `async`). Only pass `mode` values listed here. The SDKs' `run()` waits for async results; `submit()` + `wait()` split the two steps.

**curl**

```bash
curl https://api.sandbase.ai/v1/run \
  -H "Authorization: Bearer $SANDBASE_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model": "hyper3d/rodin/v2", "images": "https://static.sandbase.ai/examples/hyper3d/rodin/v2/input_input_image_urls_0.png"}'
```

**Python** ([sdk/python](../../../../sdk/python))

```python
from sandbase import SandBase

result = SandBase().run('hyper3d/rodin/v2', {'images': 'https://static.sandbase.ai/examples/hyper3d/rodin/v2/input_input_image_urls_0.png'})
print(result["outputs"])
```

**TypeScript** ([sdk/typescript](../../../../sdk/typescript))

```ts
import { SandBase } from "@sandbaseai/sdk";

const result = await new SandBase().run("hyper3d/rodin/v2", {
  "images": "https://static.sandbase.ai/examples/hyper3d/rodin/v2/input_input_image_urls_0.png"
});
console.log(result.outputs);
```

**Go** ([sdk/go](../../../../sdk/go))

```go
c, _ := sandbase.NewClient("")
run, err := c.Run(ctx, "hyper3d/rodin/v2", sandbase.Params{
	"images": "https://static.sandbase.ai/examples/hyper3d/rodin/v2/input_input_image_urls_0.png",
})
```

With plain HTTP, async runs return `{"id", "status": "pending"}`. Poll until `completed` or `failed`:

```bash
curl https://api.sandbase.ai/v1/run/$RUN_ID -H "Authorization: Bearer $SANDBASE_API_KEY"
```

## Parameters

| name | type | required | description |
|---|---|---|---|
| `seed` | integer |  | Seed (0-65535). range 0–65535 |
| `TAPose` | boolean |  | Generate characters in T-pose or A-pose for rigging. default `false` |
| `addons` | string |  | Optional add-on. HighPack (4K textures, high-poly) is billed +$0.80. one of: `HighPack` |
| `images` | array | yes | 1 to 5 images of the object.  |
| `prompt` | string |  | Optional text prompt to guide generation. Generated from the images when empty.  |
| `material` | string |  | PBR, Shaded (baked lighting) or All (both). one of: `PBR`, `Shaded`, `All`; default `"All"` |
| `quality_mesh_option` | string |  | Mesh density and topology. Quad gives smooth surfaces, Triangle gives detailed geometry. one of: `4K Quad`, `8K Quad`, `18K Quad`, `50K Quad`, `2K Triangle`, `20K Triangle`, `150K Triangle`, `500K Triangle`; default `"500K Triangle"` |
| `geometry_file_format` | string |  | Output file format. one of: `glb`, `usdz`, `fbx`, `obj`, `stl`; default `"glb"` |
